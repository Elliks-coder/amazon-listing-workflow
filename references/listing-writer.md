# B · Listing Writer

根据本品证据和目标站点规则写稿。在自然可读的前提下，优先写高意图搜索词、会改变购买决定的信息及其具体用法。先把 [锁定的 Top 3](listing-research.md#写前锁定-top-3-与字段落位) 放进标题和 Item Highlights，再安排五点和长描述。无需为字数增加句子。

## 文案字段

- **标题 / Item Name**。按「核心风格或修饰词 + 搜索量最高且匹配的品类大词与决定性的供电/安装词 + 数量或关键规格」组句。类目要求品牌时预留位置，空间不足时先删低价值装饰词。适用 75 字符上限时以 **65–75 字符**为信息充足时的目标，事实说完整即可收尾。
- **Item Highlights**。用逗号分隔短语承接标题放不下的 Top 3、硬件规格、安装/供电方式、可比较的数值以及高意图场景。适用 125 字符上限时以 **105–125 字符**为信息充足时的目标。删掉 `easy wall mounting`、`great decor` 等未提供可判断细节的空泛词组。
- **加拿大站示例**。以下假设免接线、容量、充电方式及光色档位均已有产品证据。标题 75 字符，`Rustic Battery Operated Wall Sconces, Set of 2, Wireless Farmhouse Lanterns`。Highlights 113 字符，`No wiring, 4000 mAh E26 bulbs, USB-C charging, 3 light colour settings, woodgrain backplates, bedroom and hallway`。实际出稿按品牌、SKU 及证据调整用词。
- **长描述**。按场景开场、功能解释、规格或使用条件三段展开。把长尾精准词融入真实的使用情境、操作或选购细节。
- **A+ 草稿**。根据可用资料给出与五点互补的模块和配图建议。内容如造型细节、使用画面或拆装步骤。有权限和所需素材时按适用模板核对。

## 五点 / About this item

每条用**可搜索的小标题 + 一个购买顾虑及可核实的回答 + 具体使用情境**。情境可以是一个动作、时机或摆放位置，能与事实合写一句。小标题用 `No-Wiring Installation`、`USB-C Rechargeable Bulbs` 等有产品依据的词组。写场景时给房间和具体位置，如卧室床头、走廊边柜、客厅壁炉两侧。

灯具按调研确定的主要顾虑排先后。默认顺序如下。

1. 解决首要购买顾虑。无线壁灯优先讲已证实的免布线、安装方式和适用表面。最强购买理由确实是造型时，可把图片支持的视觉差异放第一。
2. 说明供电、怎样取下或充电，以及可核实的单次续航和条件。
3. 写灯效与控制，明确遥控或触摸能操作什么，以及已核实的色温、调光或定时。
4. 写可决定选购的材质、工艺或尺寸。关键尺寸可具体说明适合哪种位置。
5. 写具体空间和已确认的包装清单。每个场景说明灯放哪里或解决什么需求。

每个事实讲清一次。删掉同义反复、泛化的家居氛围句和通用装修建议。五点无通用最低长度，**200–400 字符仅供证据充分时参考**，适用类目上限照常核查。证据只有一句就写一句，缺失的主题交给写前规格核实或简报。独立事实不足五条时，直接出稿场景保留有依据的条目，并把空缺列在内部简报。

## 后台 Search Terms

从已经筛过的词库挑仍有价值的词，逐词对照**标题、Item Highlights、五点和长描述**，删除前台已出现的词及重复单复数等冗余写法。剔除冲突属性、无关词、品牌、ASIN 和不提供新检索信息的连接词。只有删去重复成分后仍保留准确含义的词才可选。把剩余的高相关同义词、长尾属性或场景词用空格串成一行，在目标站的计量限制内尽量填充。有价值且未覆盖的词用完时交付实际长度。加拿大站按 [字节规则](listing-audit.md#加拿大站参考) 核对。

## 预览和简报

使用最终审核过的字段做可打开的商品详情预览，沿用亚马逊商品页的信息顺序并采用独立视觉样式。展示本品主图、标题、标题下方单独一行 Item Highlights、About this item、长描述和适用的 A+ 草稿。工具支持时用 Sites 等生成可浏览的页面，核对能打开、商品图能显示、字段与最终稿一致。只有用户有相应数据时才展示售价、评分和库存。后台词和调研资料单独提供给卖家，自行核验时可在预览中作为卖家字段展示。

同时交付可复制的 Listing、最终关键词库与筛词记录，以及简报。简报解释高度相关的选样依据、五点回答了哪些买家问题、Top 3 实际落在哪个字段、哪些词没有覆盖及原因、后台还覆盖了哪些词，以及仍需确认的商品信息。用实际文案里的词和真实数据说明，不把关键词覆盖描述成排名或推荐承诺。
