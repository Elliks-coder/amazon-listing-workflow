# A · Listing Research

## 选样与写前核验

1. 根据商品图片和资料确认商品形态、主要功能、安装或供电方式、核心购买场景、关键规格和已知价格带。先按购买者会考虑的可替代性筛选，再看近期表现。
2. 优先核对用户本次提供的同类 ASIN。样本不足时，用目标站点语言的品类词或关键属性调用卖家精灵 `asin.list`，用 `asin.detail`、`asin.content.list` 或目标站公开商品页交叉核对标题、主图、五点和关键规格。在高度相似的商品中优先选表现较好的款，形成 **5–10 款**。同一型号不同颜色、尺寸或套装原则上只选一个代表。比较同站点、同时间窗口和同销量口径，注明父体或代表变体数据、估算销量或可核实的销售依据。高相关样本不足时保留真实数量和缺口。
3. **开始写稿前**，在当前对话发出本次自行找的每一款竞品的主图、可点开的目标站 Amazon 商品链接、ASIN 和一句相关理由。优先直接展示能核实的原主图，展示受限时附可点开的原图链接。逐款确认图片与所选 ASIN 或变体一致。把这条消息作为写作前的独立交付。用户要求先确认时等待反馈，已有反馈则替换或补齐样本，再反查。有自行补选时也适用这一步。
4. 用户指定的长期写作参考见 [参考 ASIN](listing-writer.md#长期写作参考)。它们只有与本次商品高度相似且在目标站可核实时，才纳入本次反查样本。查看入选款的实际 Listing，记录首条五点、可核实的规格和买家顾虑。把竞品反复优先回答的问题与买家评论或问答核对，找出本品的 1–3 个关键购买问题并按影响排序。交给写作模块时记录问题、来源 ASIN 或评论、本品证据及缺项。需要时用 `asin.review.list`，注明评论是否混有父体的其他变体及实际覆盖。

## 反查与筛词

用卖家精灵 MCP **`keyword.asin.list`（品找词／ASIN 流量词反查）**，工具名为 `mcp__ss_mcp__keyword_asin_list`。入参使用目标站 `marketplace` 和 5–10 个已入选的 `asins`，近 30 天用 `dataRange=LAST_30_DAYS` 并省略 `month`。读取 `keyword`、`searchVolume`、`matchedAsins`，按需取 `trafficShare`、`products` 或 `titleDensity`。核对实际分析覆盖和返回周期。只有用户指定 ABA 时才用 `keyword.aba.list`。滚动的出词窗口和单词的月搜索量估算分别记录。空值、未收录和真实零值按原口径标明。

| 层级 | 判定依据 | 优先位置 |
|---|---|---|
| 大词 | 清楚体现商品品类或主要购买意图，在样本中有相对高的搜索量。竞争强度按实际指标判断，缺数据时留空。 | 标题中的品类表达 |
| 核心词 | 决定选购、且有本品证据的功能或属性，如充电、防水或户外。 | Top 3 优先落在标题或 Highlights，其余用在对应字段 |
| 长尾精准词 | 明确的结构、规格、使用场景或人群，符合本品的用途。 | Item Highlights、五点、长描述。前台未用且相关的词也可补后台。 |

按搜索意图合并显然重复的写法、大小写或单复数。剔除无关流量词、竞品品牌或型号、与本品配置冲突的词及需要证据但暂时无法证实的词。优先留匹配商品的词，再结合竞品命中、流量及竞争数据排序。对相近词保留有合理搜索价值的独立写法。记录每个剔除词或可核对的重复组与理由。卖家精灵不可用或部分 ASIN 未收录时，可参考用户给的导出或目标站公开商品页，将补充词标为观察词并记录覆盖和缺口。

## 写前锁定 Top 3 与字段落位

- 从去重后的**大词和核心词合计锁定 Top 3**。先选一个能准确命名产品的品类大词，再选最影响购买且有证据的供电、安装、数量或关键规格表达。对同一意图按目标站搜索量估算、流量及购买意图择优。外站反查可补候选词，优先用目标站数据排定。可核验词不足三个时，记录实际数量和数据缺口。
- 写前为每项记录**原词｜目标站数据｜本品证据｜拟放字段｜拟用词组**。锁定的词组要求 **100% 落在标题与 Item Highlights 两个字段内**。核对原词或词库已登记的单复数、连字符等同义写法，保留足以表达原搜索意图的完整词组，仅在五点出现视为未覆盖。两字段各自遵守适用上限。
- 写稿及审核逐项打勾，填入实际字段和原文。对照本品核查 `Battery Operated`、`Wireless`、`No Wiring`、`Farmhouse` 等已确认且高意图的候选词。对高流量但缺证或冲突的候选词，以及锁定后仍未落位的词，在简报中标红 `🔴 未覆盖`，逐词写清原因和可用替代词或位置。纯文本保留同一标记。

## 词库交付

写完 Listing 后，把本次使用的**保留词库和筛词记录**交给用户。保留词列关键词、层级、意图、本品对应事实、反查来源或命中 ASIN、指标和周期、在实际文案中的位置（也可标为备用）。单独列出 Top 3 的覆盖数、实际字段和原文，保留高流量词的未覆盖原因。筛词记录列词、筛掉的原因及重复时的归并对象。让用户能按原词、使用位置和依据核对。另附候选卖点的事实、证据位置及适用 SKU，供写作和审核。
